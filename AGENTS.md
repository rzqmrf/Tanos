# Aturan Kerja & Komunikasi (User Preferences)

1. **Bahasa Komunikasi:** Always communicate exclusively in Bahasa Indonesia.
2. **Konfirmasi Sebelum Edit (No Auto-Edit):**
   - JANGAN melakukan edit kode/berkas secara otomatis tanpa meminta konfirmasi terlebih dahulu.
   - Jelaskan rencana edit dan tunggu persetujuan dari user sebelum mengeksekusi edit.
3. **Konfirmasi Sebelum Git Push/Pull:**
   - JANGAN melakukan `git push` atau `git pull` secara otomatis.
   - Selalu minta konfirmasi pengguna sebelum menjalankan aksi Git push/pull.
4. **Format Laporan & Proposal Perubahan (Setelah Scanning/Analisa):**
   Setelah melakukan scanning atau analisa kode di workspace, berikan daftar rekomendasi perbaikan/pengerjaan dengan format wajib:
   - **Skala Prioritas** (Seberapa krusial perubahan/code edit tersebut: High / Medium / Low).
   - **Use Case & Alasan Perubahan**.
   - **Estimasi Before & After** (Perbandingan kondisi kode/tampilan sebelum dan sesudah diedit).
